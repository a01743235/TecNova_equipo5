# TecNova Sinaloa - Equipo 05 (Landing Page)

Landing page oficial desarrollada para el **Equipo 05: TecNova Sinaloa**, lista para publicarse en **GitHub Pages**.

## Características
- **Identidad Visual Oficial**: Respeta la paleta institucional (#0B2E5B Azul Profundo, #1E5FA8 Azul Tec, #D4AF37 Dorado y #F4F6F8 Gris Claro) e incorpora los logotipos oficiales.
- **Fondo Animado**: Canvas dinámico con estrellas titilantes y cohetes despegando continuamente con estelas de partículas y propulsión.
- **Botón de Despegue Interactivo con Sonido**: Emite el rugido de ignición y aceleración de motores espaciales utilizando **Web Audio API** (sin dependencias de archivos de audio externos, evitando errores 404 o bloqueos de formato).
- **100% Responsive & Compatible con GitHub Pages**: Estructura lista con `index.html` en la raíz.

## Cómo publicar en GitHub Pages:
1. Crea un repositorio en GitHub (por ejemplo `tecnova-sinaloa`).
2. Sube los archivos de este directorio (o el contenido de este ZIP) a la rama `main` o `master`.
3. En GitHub, ve a **Settings** > **Pages**.
4. En **Build and deployment** / **Source**, selecciona `Deploy from a branch`, elige la rama `main` y la carpeta `/ (root)`.
5. Haz clic en **Save**. En un par de minutos tu sitio estará en vivo en `https://<tu-usuario>.github.io/<tu-repo>/`.
